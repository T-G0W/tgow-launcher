# Changelog

## 0.2.0

First public release.

- Catalog of every T-G0W repository with the tgow-launcher topic and a signed release
- Automatic detection of operating system, CPU architecture and Linux distribution
- Per user installation of portable builds, zip and tar.gz archives, Inno Setup, NSIS and MSI packages
- Automatic updates for all apps and for the launcher itself, with rollback after failed starts
- Tray icon, single instance and tgow links
- Update mode per app: automatic, notify only or off
- Several downloads at once, installers still run one after another
- Hero images and icons from the release manifest
- Library as grid or list, with a filter for installed apps and updates and sorting by name or newest release
- Keyboard shortcuts, accessible names and focus rings for every control
- OpenGL renderer first, wgpu as fallback
- List of all bundled open-source crates with their licenses
- T-GOW Launcher License: free to use, not to sell, change or pass on
- Loading window that checks for updates and installs a launcher update before the main window opens
- Cards with a screenshot banner, the description on hover and the install state always visible
- Context menus on cards and list rows, a menu next to the main action on app pages
- Popups for downloads and status under the title bar
- Back navigation from the title bar, Alt+Left and the mouse
- Slightly rounded controls, no maximizing, animations on by default
- Logo and screenshot of an app from its repository when the release brings none
